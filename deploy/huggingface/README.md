# DocPilot: public demo

Ask questions about five sample documents from a fictional company and get answers that cite their sources, or a refusal when the answer isn't there.

This Space is deployed automatically from [github.com/Gayathri2708/docpilot-rag](https://github.com/Gayathri2708/docpilot-rag) after CI passes. The visitor key is read-only, uploads are disabled, and questions are rate-limited.
